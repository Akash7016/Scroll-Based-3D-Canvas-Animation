## ✨ Introduction

This project demonstrates how to build a scroll-controlled 3D animation experience using HTML5 Canvas and JavaScript.

Instead of relying on heavy animation libraries, this implementation directly maps scroll position to animation frames. As the user scrolls, a character animates dynamically — including movement transitions and facial expression changes — creating an immersive storytelling experience.

The primary focus of this project is:

- Scroll-based animation architecture
- High-performance rendering
- Frame-by-frame animation control
- Smooth 60fps performance
- Lightweight, library-free implementation

This project is ideal for understanding advanced UI motion systems and interactive animation design.

---

## ⚙️ Tech Stack

- **HTML5 Canvas** – Rendering animation frames directly in the browser
- **JavaScript (ES6+)** – Scroll tracking, frame logic, rendering control
- **CSS3** – Layout, positioning, and smooth UI effects
- **requestAnimationFrame API** – Optimized animation loop
- **Scroll Event Handling** – Mapping scroll progress to animation frames

---

## 🔋 Features

👉 **Scroll-Controlled Animation**  
Maps scroll position directly to animation frames for precise interaction.

👉 **Frame-by-Frame Rendering System**  
Preloads image frames and renders them dynamically based on scroll progress.

👉 **Character Movement & Expressions**  
Smooth transitions between poses and facial expressions.

👉 **Optimized Rendering Loop**  
Uses `requestAnimationFrame` for high-performance 60fps animation.

👉 **Responsive Canvas Scaling**  
Canvas resizes dynamically for different screen sizes.

👉 **Lightweight Implementation**  
No animation libraries — built entirely with native browser APIs.
